# 🛡️ Smart Attendance System 2

An enterprise-grade, biometric attendance management system built with **Passkeys / WebAuthn (Face ID & Touch ID)**, **React + Vite**, **Express API**, **Drizzle ORM**, and **PostgreSQL**.

## ✨ Features

- 👤 **Face ID & Touch ID Biometric Scan:** Powered by standard `@simplewebauthn` for native hardware-bound biometric passkey registration and verification.
- 📹 **Live WebCam HUD Scanner Mode:** Real-time video preview with futuristic targeting HUD, face reticle box, and instant visual check-in status.
- 📊 **Executive Attendance Dashboard:** Auto-refreshing statistics, class-by-class attendance breakdown, weekly trend charts, and live scan stream.
- 🚨 **Tardy Watchlist:** Automatic identification of frequent tardy check-ins (Cutoff set to **07:30 AM**).
- 📁 **Reports & CSV Export Center:** Filter attendance records by date, class section, or status, and export official `.csv` reports or print clean archives.
- 🗄️ **PostgreSQL + Drizzle ORM:** Robust relational database schema for student records, attendance logs, and WebAuthn credentials.

## 🏗️ Architecture & Tech Stack

```
smart-attendance-system-2/
├── artifacts/
│   ├── api-server/         # Express REST API server with WebAuthn routes
│   └── attendance-app/     # React + Vite frontend application (TailwindCSS & Shadcn UI)
└── lib/
    ├── api-client-react/   # Type-safe React Query hooks (generated by Orval)
    ├── api-spec/           # OpenAPI specs and code generation config
    ├── api-zod/            # Zod validation schemas
    └── db/                 # Drizzle ORM database schemas & migrations
```

- **Frontend:** React 18, Vite, TailwindCSS, Shadcn UI, Lucide Icons, Recharts, Wouter Router.
- **Backend:** Node.js, Express, `@simplewebauthn/server`, Drizzle ORM.
- **Database:** PostgreSQL (with `drizzle-kit` push support).
- **Monorepo Management:** PNPM Workspaces.

## ⚡ Quick Start

### 1. Prerequisites
- **Node.js:** v20.x or higher
- **PNPM:** v9.x or higher
- **PostgreSQL:** Running locally or on Cloud SQL / Supabase

### 2. Environment Setup
Create an `.env` file in `artifacts/api-server/.env`:

```env
PORT=5001
DATABASE_URL=postgresql://postgres@localhost:5432/attendance
```

### 3. Install Dependencies
```bash
pnpm install
```

### 4. Database Setup
Create the database and push the database schema:

```bash
# Create local postgres database if needed
psql -d postgres -c "CREATE DATABASE attendance;"

# Push Drizzle schema to PostgreSQL
pnpm -F @workspace/db run push
```

### 5. Run Application
Start all monorepo dev servers in parallel:

```bash
pnpm run dev
```

The apps will be available at:
- **Attendance Web App:** `http://localhost:5173/` (or `http://localhost:5175/`)
- **API Server:** `http://localhost:5001/`
